Questions

Is paraphrasing the same as plagiarism?

No, but a paraphrase still needs a citation. Putting someone else's idea in new words means the idea is still theirs, so cite the source.

Which mode should I use for an essay?

Academic or Formal keeps the tone suitable for school work. Fluency is best if you only want smoother sentences.
